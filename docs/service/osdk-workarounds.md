# OSDK workarounds

This log records each place where a stock Apache-2.0 `@osdk/*` package cannot express what Ontos needs, and documents the workaround that Ontos uses without forking upstream packages.

## Contract

- Any pull request that adds a workaround for a stock `@osdk/*` package adds its row here. Our rule.

| Package                                                    | Limitation in stock package                                                                                                                                                                                                                                                                                                                                                                 | Ontos workaround                                                                                                                                                                                                                                              | Cost                                                                                                                                                            |
| ---------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `@osdk/maker` 0.91.0 and `@osdk/maker-experimental` 0.87.0 | Cannot carry a permission slug on an Object Type or Action Type. A `roles` key does not reach the IR, and the types of `defineObject` and `defineFunctionBackedAction` refuse a `roles` key.                                                                                                                                                                                                | The [grants file](./ontology-as-code.md#the-grants-file)                                                                                                                                                                                                      | Each type appears in 2 files. [Publish](./publish.md#grants-check) refuses any mismatch.                                                                        |
| `@osdk/maker` 0.91.0                                       | Cannot write a permission user value directly in a security policy or a submission criterion.                                                                                                                                                                                                                                                                                               | A `group` condition names a permission slug, and the Ontology service reads each group as a permission of the caller, as [Object security policies](../ontology/object-security-policies.md#conditions) specifies.                                            | A later group concept would clash with this reading.                                                                                                            |
| `@osdk/maker` 0.91.0                                       | Cannot hold the traversal path of a [Person attribute](../ontology/object-security-policies.md#person-attributes). A `userAttributes` value names only a key.                                                                                                                                                                                                                               | The optional `personAttributes` key of the [grants file](./ontology-as-code.md#the-grants-file)                                                                                                                                                               | A policy and the path of its attribute live in 2 files, and publish checks that they match.                                                                     |
| `@osdk/maker` 0.91.0                                       | Cannot hold [schema migrations](../ontology/object-edits/schema-migrations.md) of an Object Type. The schema migrations and schema lockfile of `@osdk/maker` cover only Interfaces.                                                                                                                                                                                                         | The file `.ontology/schema-migrations.json`                                                                                                                                                                                                                   | An extra file for each app, which publish sends beside the IR.                                                                                                  |
| `@osdk/maker` 0.91.0                                       | Cannot mark a Property as unique because `@osdk/maker` Property options include no unique flag.                                                                                                                                                                                                                                                                                             | A type class on each Property of the rule: `{ kind: "unique", name: "<rule name>" }`. Properties with the same `name` form 1 [Uniqueness constraint](../../GLOSSARY.md). The type class reaches the IR and the Ontology metadata unchanged.                   | A typo in `kind` or `name` gives no compile-time error. Publish refuses invalid definitions.                                                                    |
| `@osdk/maker` 0.91.0                                       | Does not check the 3-hop limit of a derived property on an Object Type. Its `derived` datasource accepts any number of links.                                                                                                                                                                                                                                                               | Publish refuses a derived property with more than 3 hops, and the error names the Object Type and the Property.                                                                                                                                               | The author learns of the limit at publish, not when maker runs.                                                                                                 |
| `@osdk/maker` 0.91.0                                       | Refuses a derived aggregation on a Decimal Property inside `defineObject`. `validateAggregations` omits `"decimal"` from `isNumeric`, `isPrimitive`, and `isCollectible`, so `defineObject` refuses `sum`, `avg`, `min`, `max`, `exactCardinality`, `approximateCardinality`, `collectList`, and `collectSet`. Ontos supports derived aggregations on a Decimal Property of an Object Type. | Declare the Decimal Property and a `datasources` array in `defineObject`, then attach the `derived` datasource to the returned Object Type with `object.datasources?.push(...)`. The Ontology service validates and compiles the derived property at publish. | The author learns of a bad derived definition at publish, not when maker runs. A later maker release that clones `datasources` on return breaks the workaround. |
| `@osdk/client` 2.92.0                                      | Exposes Object Type derived property loading only via `$UNSTABLE_loadOntologyDefinedDerivedProperties`.                                                                                                                                                                                                                                                                                     | App code names each derived property in `select`, sets the `$UNSTABLE_` option, or enables `ONTOLOGY_LOAD_DERIVED_PROPERTIES=true` on the deployment.                                                                                                         | A rename of the option in a later client breaks app code that sets it.                                                                                          |
| `@osdk/client` 2.92.0 and `@osdk/api` 2.92.0               | Types a derived `sum` or `avg` of a Decimal as `double`, whereas Ontos returns an exact string as [Types](../ontology/object-link-types/derived-properties.md#types) specifies. `decimal` is also absent from `WithPropertiesNumerics`.                                                                                                                                                     | App code casts the value to `string` and calls `new Big(value)` before doing arithmetic. To subtract a stored Decimal from a derived `sum`, app code casts the operand.                                                                                       | 1 cast at each place that reads a Decimal derived value.                                                                                                        |
| `@osdk/client` 2.92.0                                      | Returns a Decimal value as a `string` rather than a decimal object.                                                                                                                                                                                                                                                                                                                         | App code and Functions call `new Big(value)` of `big.js` before doing arithmetic.                                                                                                                                                                             | 1 conversion at each place that does math.                                                                                                                      |
| `@osdk/functions` 1.30.0                                   | Has no `Decimal` type for Function inputs.                                                                                                                                                                                                                                                                                                                                                  | The app declares `type Decimal<T extends string = string> = T & { __decimalBrand?: void }`, and the CLI maps the name `Decimal` to a `decimal` Action parameter.                                                                                              | 1 line in each app.                                                                                                                                             |
| `@osdk/api` and `@osdk/generator` 2.92.0                   | Has no `decimal` Query Function output type.                                                                                                                                                                                                                                                                                                                                                | The Ontology metadata gives the output as `string`, and the doc comment of the Function documents that it is a Decimal.                                                                                                                                       | The schema does not say "Decimal", so callers read the description.                                                                                             |
